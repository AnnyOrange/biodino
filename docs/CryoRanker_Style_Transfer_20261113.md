# CryoRanker 式质量排序迁移：独立比较协议（2026-11-13）

## 与已有结果的关系

保留 `ood-author-task-frozen-fm-v2` 的 Cryo-IEF 真实结构、真实质量与模拟姿态冻结 1-NN 结果，不重命名、不覆盖。本文档的新实验是**有监督、全编码器微调的质量排序**，结果单列，不能与冻结 1-NN Top-1 作绝对分数差。

Cryo-IEF 论文的 CryoRanker 在约 4,239 万个作者标注颗粒上训练，使用二输出分类头、质量极端样本的交叉熵及分数配对 margin ranking，随后在真实颗粒上评估排序，并用于 CryoWizard 的三维重建流程。作者 GitHub 当前发布了推理代码与权重，未发布完整的训练入口及对应 4,239 万颗粒的可复现训练清单。因此本实验称“CryoRanker 式”，不得称作者训练复现或同训练集公平比较。

来源：[论文](https://www.nature.com/articles/s41592-025-02916-8)、[预印本](https://www.biorxiv.org/content/10.1101/2024.11.04.621604v1)、[作者代码](https://github.com/westlake-repl/Cryo-IEF)。

## 首轮锁定设置

- 输入：作者公开的四个真实项目 EMPIAR-10535、11043、11387、11388，各 80,000 颗粒；以作者 2-D class 的 0–1 质量分数作连续标签，所有同一项目颗粒只属于同一划分。
- 四个留一项目折：沿用 `CRYO_LABEL_EFFICIENCY_PLAN.md` 的 train/validation/test 项目表。先做 10535 测试折的 BioDINO-L lw5 pilot，随后四折、每折五个训练 seed；同一代码与抽样配置下增加 Cryo-IEF 编码器微调对照，不能仅拿论文原文 42M 模型作同训练预算对照。
- 训练：256 输入，二输出头，全部编码器参数可训练；连续标签相异的批内有序对使用 `max(0, 0.2-(p_i-p_j))` 均值；质量 `>0.7` 和 `<=0.3` 的样本做交叉熵，中间质量只参与排序。两项相加。AdamW、编码器学习率 1e-5、头学习率 1e-4、五 epoch，seed 固定。以上批内配对与损失归一化为本项目明确实现选择；未认证与作者未发布训练脚本逐位一致。
- 验证项目以 top 10% 预测排序颗粒的平均作者质量分数选 epoch。测试项目仅运行一次；保存逐粒子预测、样本 ID、权重与代码哈希。
- 报告逐项目 Spearman、仅高/低极端的 AUROC/AP、top 10/25/50% 的平均质量与高质量比例；四项目等权，再对五个 seed 报均值和 SD。按采集项目而非颗粒数量理解独立性。
- 作者原文的 CryoRanker 权重可在同一四项目上**只做零额外训练的部署基线**；它与本实验的三项目监督微调训练数据量不同，必须独立标注。CryoWizard 三维重建为后续验证，未做前不声称分辨率提升。

执行入口：`scripts/run_cryo_quality_ranker_transfer.py`。原三档质量分类实验保持独立，不把其 macro-F1 当作排序指标。
